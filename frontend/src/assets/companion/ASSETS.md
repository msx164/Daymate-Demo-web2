角色透明通道已读取验证，左上角 alpha=0，存在完全透明像素。保留生成器原始 alpha，不使用黑色、白色或棋盘格图案模拟透明。背景和角色分层，由前端组合。

消费组件为 `components/CompanionScene.jsx` 和 `components/CompanionAvatar.jsx`。更换默认素材时新增版本文件并更新 import，保留本版本；当前没有用户文件上传或自定义角色导入界面。显示偏好存于当前浏览器或桌面配置的 localStorage，不上传模型服务。

第十五阶段的两个变体使用内置 image_gen 编辑原图，完整提示词及参照文件记录在 [state-prompts.json](./state-prompts.json)。两图保留原尺寸、衣着与站位；分别增加托腮、开口及交流手势，未覆盖原图。透明通道验证两图左上角 alpha=0、角色中央 alpha=253。

这是静态 2D 状态立绘，轻微呼吸、倾身、点头和一次招呼由 CSS 生成，暂停和保存时静止。关闭轻微动作或系统偏好减少动态效果后停止动画，状态立绘仍切换。没有人物骨骼、独立表情层、逐音素口型或真实视频。开口立绘只代表朗读状态，不随声音开合。生成的人物作为虚构角色使用，不对应真实人物。
